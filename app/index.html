THE IDEA, IN PLAIN ENGLISH

Git is the plan. Argo CD is the watchful teammate.

3 simple parts
01
⌘

Describe it in Git

Application files and Kubernetes manifests live together in a version-controlled repository. A reviewed commit becomes the desired state.

02
↻

Argo CD compares

Argo CD reads the repository and compares its manifests with the cluster. It reports differences and can reconcile approved changes.

03
▤

Kubernetes runs it

Kubernetes schedules the container and keeps the requested replicas running. A Service gives the dashboard a stable in-cluster address.

↗

One important boundary: Argo CD deploys Kubernetes resources; it does not build Docker images. Build and load the image separately before changing the Deployment image tag.
